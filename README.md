# Reel Editor

Skill per Claude che monta reel verticali in motion graphics partendo dal girato: taglio, sottotitoli parola per parola, scene animate, musica ed effetti.

## Scarica

Zip pronto: https://github.com/francescolabriola1011-star/reel-editor-skill/releases/latest/download/reel-editor-skill.zip

## Installa

Claude.ai: Impostazioni, Capacita', Skill, carica lo zip.

Claude Code: scompatta la cartella `reel-editor` dentro `~/.claude/skills/`.

Le istruzioni complete sono in `reel-editor/SKILL.md`.
